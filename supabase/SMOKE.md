## 계정 A (OWNER)

1. 카카오 로그인 → 홈에 개인 가계부가 보이는지
2. 워크스페이스 전환 → **새 워크스페이스 만들기** (모달, prompt 아님) → 공유 가계부 생성
3. 설정 → 내 워크스페이스 관리 → 초대 링크 복사
4. 공유 가계부에 식비 지출 1건 등록 (결제자 = 나)

## 계정 B (초대 수락)

1. 시크릿 창 또는 다른 기기에서 초대 링크로 접속
2. 카카오 로그인 후 참여 성공
3. 같은 공유 가계부가 선택되는지, A가 넣은 지출이 보이는지
4. B도 지출 1건 등록 (결제자 = B)
5. 설정 탭 **정산**에서 선택한 달 기준으로 1/N 이체 안내가 나오는지
6. A 기기에서 Realtime 으로 B 내역이 갱신되는지
